4. Implementation clarifications
--------------------------------
- The app integrates a remote REST API at `https://labs.anontech.info/cse489/t3/api.php`.
- For web CORS constraints, requests are proxied via `https://corsproxy.io/` when required.
- API requests use `application/x-www-form-urlencoded` and `lat`/`lon` fields; updates use HTTP `PUT` with `id` in the body.
- DELETE uses query param `?id=` and is supported from web builds.
- No server-side code is contained in this repository; only Flutter client implementation.
